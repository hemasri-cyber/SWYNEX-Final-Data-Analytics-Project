# Exploratory Data Analysis (EDA)

## Objective
To explore Netflix movies and TV shows and identify meaningful patterns in the content library.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Key Insights

1. **Content Type:** Movies account for approximately 69.6% of titles, while TV Shows account for 30.4%.
2. **Release Trends:** The year 2018 had the highest number of titles by release year in the analysis.
3. **Top Country:** The United States had the highest number of titles in the dataset.
4. **Content Rating:** TV-MA was the most common content rating.
5. **Popular Genre:** International Movies was the most frequent listed genre.

## Conclusion
The analysis highlights the distribution of Netflix content by type, release year, country, rating, and genre.
