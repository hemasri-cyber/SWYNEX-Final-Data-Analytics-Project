# Netflix Content Analytics Dashboard

## Objective
To present Netflix content analysis through clear and interactive visualizations.

## Tool Used
Microsoft Power BI

## Dashboard Components
- Total Titles KPI
- Movies vs TV Shows comparison
- Titles released by year
- Content rating distribution
- Top countries by number of titles
- Date Added filter

## Purpose
The dashboard helps users explore Netflix's content library and identify patterns across content types, release years, ratings, and countries.
