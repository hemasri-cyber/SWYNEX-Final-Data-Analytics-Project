# Netflix Content Analytics – Final Data Analytics Project

## 1. Project Overview
This project analyzes Netflix movies and TV shows to understand content distribution, release trends, ratings, and country-wise patterns.

## 2. Problem Statement
The goal is to explore Netflix's content library and present useful insights through data analysis and visualizations.

## 3. Dataset
- Dataset: Netflix Movies and TV Shows
- Records: 8,807 rows
- Columns: 12
- Format: CSV

## 4. Tools and Technologies
- Python
- Pandas
- Matplotlib and Seaborn
- Google Colab
- Microsoft Power BI
- GitHub

## 5. Project Workflow
1. Dataset inspection and data cleaning
2. Exploratory Data Analysis (EDA)
3. Visualization of important patterns
4. Dashboard development
5. Summary of key findings

## 6. Key Findings
- Movies account for approximately 69.6% of titles.
- TV Shows account for approximately 30.4%.
- 2018 was the peak release year in the analysis.
- The United States had the highest number of titles.
- TV-MA was the most common content rating.

## 7. Project Structure
- `data/` – Dataset information
- `data-cleaning/` – Data cleaning documentation
- `eda/` – EDA findings and insights
- `dashboard/` – Dashboard documentation

## 8. Results
The project demonstrates how data cleaning, exploratory analysis, and dashboard visualizations can help summarize a content library.
